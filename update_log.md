# Zibll Release Notes

## 1.0.0

- Initial official open source release of Zibll by the official maintainer.
- Distributed under GPL-2.0-or-later with public source code, community review, and contribution workflow.
- Unified the public package version to `1.0.0`.
- Retained official documentation and tutorial links so users can continue to follow existing usage guides.
- Added open source documentation, security policy, third-party notices, provenance notes, and release checklist.
- Kept payment, order, membership, SMS, OAuth, logistics, content-audit, and search modules as site-owner configurable features.
- Added nonce verification to the chunked upload merge action.
- Replaced the file-size detection fallback with a PHP-native implementation.
- Removed unused local system files and regenerated the release checksum manifest.
