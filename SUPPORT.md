# Support

For official documentation, tutorials, release announcements, and service information, use the official website:

<https://www.zibll.com>

For source-code issues, reproducible bugs, documentation corrections, and contribution discussion, use the official GitHub repository.

Before reporting an issue:

- Confirm you are using an official Zibll release.
- Check the release notes and existing issues.
- Provide environment information and reproducible steps.
- Do not include real keys, private configuration, database dumps, or personal data.

Security reports should follow `SECURITY.md`, not public issues.
